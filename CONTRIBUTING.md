# Como contribuir

Obrigado por considerar uma contribuição para o Fabio7X Mini Game Kit. O objetivo é manter o projeto fácil de abrir, compreender e reutilizar.

## Antes de enviar uma mudança

Abra `index.html` em um navegador e teste a mecânica afetada. Uma contribuição deve preservar o funcionamento com mouse, toque e, quando existir, teclado.

| Tipo de mudança | Critério mínimo |
| --- | --- |
| Nova mecânica | Incluir explicação curta, estado inicial, reinício e limpeza de eventos. |
| Ajuste visual | Manter contraste, leitura em tela pequena e preferência por movimento reduzido. |
| Correção | Descrever como reproduzir o problema e como a alteração foi validada. |
| Documentação | Usar português claro e links relativos quando possível. |

## Processo sugerido

Faça um fork, crie uma branch descritiva, mantenha o escopo pequeno e abra um pull request explicando o que mudou. Não inclua chaves, arquivos de conta, rastreadores ou dependências desnecessárias.

As contribuições serão avaliadas por clareza, acessibilidade, leveza e utilidade para quem está aprendendo a criar jogos web.
